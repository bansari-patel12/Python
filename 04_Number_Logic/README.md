# 🟡 Loops & Numbers Logic Challenges (Python Implementation)

This repository contains Python solutions for core number-based logic challenges. These programs focus strictly on loops (`for` and `while`), conditional blocks (`if-elif-else`), and mathematical operators (`//` floor division and `%` modulus)—**without using functions (`def`) or lambda expressions**.

---

## 🚀 Solved Challenges

### 1. Check if a Number is Prime
Takes a number from the user and checks if it is a prime number (divisible only by 1 and itself).

### 2. Print Prime Numbers (1 to 100)
Iterates through 1 to 100 and displays all the prime numbers found in that range.

### 3. Check if a Number is a Perfect Number
Checks if a given number is equal to the sum of its proper divisors, excluding the number itself (e.g., 6 = 1 + 2 + 3).

### 4. Check if a Number is an Armstrong Number
Verifies if a number equals the sum of its digits raised to the power of the total number of digits (e.g., 153 = 1³ + 5³ + 3³).

### 5. Count Zeros Inside a Number
Extracts digits one by one to count how many times the digit `0` appears inside the number.

### 6. Find First and Last Digit of a Number
Extracts and prints the very first (leftmost) and the very last (rightmost) digit of an integer.

### 7. Sum of All Even Digits
Iterates through the digits of a number and calculates the total sum of only the even numbers.

### 8. Sum of All Odd Digits
Iterates through the digits of a number and calculates the total sum of only the odd numbers.

### 9. Find the Largest Digit in a Number
Scans all digits within a number to determine the maximum value (e.g., `58321` → `8`).

### 10. Find the Smallest Digit in a Number
Scans all digits within a number to determine the minimum value (e.g., `58321` → `1`).

---

## 🛠️ Key Concepts Covered
* Loops (`for` and `while` loops)
* Digit Extraction using Modulus (`%`) and Floor Division (`//`)
* Conditional Counter and Sum Accumulators
* Prime Testing Flags
