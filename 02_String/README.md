# 🟢 Level 2 — Strings (Python Implementation)

This repository contains Python solutions for the **Level 2 String Challenges**. These programs cover essential string manipulation concepts, including counting characters, checking properties, and reversing strings using loops and built-in methods.

---

## 🚀 Solved Challenges

### 1. Find the Length of a String
Calculates the total number of characters in a given string using the `len()` function.

### 2. Print First and Last Character
Extracts and prints the very first and the very last character of a string using index positioning (`[0]` and `[-1]`).

### 3. Reverse a String
Reverses the input string using Python's slicing technique (`[::-1]`) or a loop.

### 4. Check if a String is a Palindrome
Checks if a string reads the same backward as forward (e.g., "radar" or "madam").

### 5. Count Vowels in a String
Iterates through the string to count the total number of vowels (`a, e, i, o, u` both uppercase and lowercase).

### 6. Count Consonants in a String
Counts all alphabetical characters that are not vowels, ensuring spaces and numbers are excluded.

### 7. Count Spaces in a String
Finds the total number of blank spaces present within a sentence or string.

### 8. Count Occurrences of a Particular Character
Takes a specific character from the user and counts how many times it appears in the string.

### 9. Identify/Count Uppercase and Lowercase Letters
Uses `.islower()` and `.isupper()` to separately count lowercase (`a-z`) and uppercase (`A-Z`) letters.

### 10. Check if Two Strings are Same
Compares two different string inputs to verify if they are exactly identical.

---

## 🛠️ Concepts Covered
* String Slicing & Indexing
* Conditional Statements (`if-elif-else`)
* Loops (`for` loops)
* Built-in Methods (`.isalpha()`, `.islower()`, `.isupper()`, `len()`)
