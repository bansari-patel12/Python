# 🟡 Level 3 — Loops & Numbers (Python Implementation)

This repository contains Python solutions for the **Level 3 Logic-Building Challenges**. These programs focus strictly on loops (`for` and `while`), conditional blocks, and mathematical algorithms—**without using functions (`def`) or lambda expressions**.

---

## 🚀 Solved Challenges

### Q1. Print Prime Numbers (1 to 100)
Iterates from 1 to 100 and prints all numbers that are divisible only by 1 and themselves.

### Q22. Fibonacci Series (First 10 Numbers)
Generates and displays the first 10 numbers of the Fibonacci sequence (`0, 1, 1, 2, 3, 5, 8...`) using basic variables.

### Q3. Check Armstrong Number
Takes a number from the user and checks if the sum of the cubes of its digits equals the number itself (e.g., 153 = 1³ + 5³ + 3³).

### Q4. Print Armstrong Numbers (1 to 500)
Runs a loop from 1 to 500 to find and print every Armstrong number in that range.

### Q5. Find All Factors of a Number
Takes an integer input and prints all the numbers that can perfectly divide it without leaving a remainder.

### Q6. Check Perfect Number
Checks if a given number is equal to the sum of its proper positive divisors (excluding the number itself, e.g., 6 = 1 + 2 + 3).

### Q7. Find GCD / HCF of Two Numbers
Calculates the Greatest Common Divisor (Highest Common Factor) of two numbers using a loop-based algorithm.

### Q8. Find LCM of Two Numbers
Finds the Lowest Common Multiple of two user-input integers using loop logic.

### Q9. Sum of All Even Digits in a Number
Extracts individual digits from a given number using mathematical operations (`%` and `//`) and adds up only the even ones.

### Q10. Right-Angled Triangle Star Pattern
Uses nested loops to print a clean right-angled triangle pattern made of stars (`*`).

---

## 🛠️ Concepts Covered
* Loops (`for` and `while` loops)
* Nested Iterations
* Number Splitting (`//` floor division and `%` modulus)
* Conditional Flags and Counters
